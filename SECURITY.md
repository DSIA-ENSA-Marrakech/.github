# Security policy

Do not disclose vulnerabilities, secrets or personal data in public issues or pull requests.

If private vulnerability reporting is enabled on the affected repository, use its Security tab. Otherwise, use the club’s official website or LinkedIn page to request a private reporting channel; do not include sensitive technical details until the channel is confirmed.

Include the affected repository and version, impact and safe reproduction information through the private channel. Maintainers should coordinate fixes and disclosure with affected parties.
